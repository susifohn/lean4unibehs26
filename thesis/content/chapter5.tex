Libraries are collections of definitions and proved theorems which can be used in own proofs. \\

We assume here the author of the library is is trustworthy and honest. In case we cannot be sure of that e.g. if the source is some AI-generated library not proved yet, then the approach is different and we have to be careful. One could just define some rubbish and the result would be some approved theorem (blue checkmarks) if using such source for own proofs. Ref: \href{https://lean-lang.org/doc/reference/latest/find/?domain=Verso.Genre.Manual.section&name=validating-blue-check-marks}{validating blue check marks}

To avoid such state, one can list and check all dependent definitions and axioms. Use \texttt{print axioms} for that.
